loader can insmod it and nothing that bound to the stock

Three levels, each reported on its own:

1. **NAME** - the build emits a .ko with the stock file name.

   local symbols included. The stock blob's locals are the
   driver's own functions, so a replacement that does not
   have them is not the same code.
3. **DEPS** - it imports nothing the stock one did not, and
